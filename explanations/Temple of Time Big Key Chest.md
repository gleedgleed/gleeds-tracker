# Temple of Time Big Key Chest

In Temple of Time. The door to the chest opens once a set of **floor switches is held down** -- use the **Dominion Rod** to move statues and Helmasaur-armor objects onto each switch simultaneously.

Requires: **Dominion Rod**.
