# Ilia Memory Reward

Inside **Renado's house** (the sanctuary) in Kakariko Village, where Ilia is staying after losing her memory.

**Show her the charm** (Ilia's Charm / Horse Call) to trigger the memory and receive the item.

Requires: **Ilia's Charm**.
