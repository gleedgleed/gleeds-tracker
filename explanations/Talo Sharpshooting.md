# Talo Sharpshooting

The **target-shooting minigame** Talo runs from the top of the **watchtower** in Kakariko Village.

Climb up the watchtower **after the Goron Mines is cleared** (Talo only sets it up post-Mines), talk to Talo, and shoot **3 targets with the Bow** to win.

Requires: **Bow**, Goron Mines cleared.
