# Snowboarding Snowy Tree Top Rupee 3

While Snowboarding down the mountain, leap onto the tree tops that have snow ledges on them.

Requires: Can Defeat Shadow Beast, Can Bonk Tree or Can Complete Snowpeak Ruins.
