# STAR Prize 2

The **STAR Game minigame** in west Castle Town (Purlo's tent).

After you've **completed it once** and obtained the **Double Clawshot**, return and **complete it a second time** (this run uses the Double Clawshot's faster reach). Second clear = second prize.

Requires: **Double Clawshot**, STAR Prize 1 already won.
