# Zoras Domain Light All Torches Chest

Underwater in **Zora's Domain throne room**, where unlit torches ring the sunken area.

Use the **Lantern to light every torch**; the chest appears underwater. Equip **Iron Boots** to sink to it.

Requires: **Lantern**, **Iron Boots**.
