# Lake Hylia Shell Blade Grotto Chest

In the **grotto below Falbi's house** at Lake Hylia (wolf-dig grotto).

**Defeat all the Shell Blades** inside to reveal the chest.

Requires: **Wolf Form** (Shadow Crystal) to enter.
