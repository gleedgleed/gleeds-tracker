# Zoras Domain Extinguish All Torches Chest

Underwater in **Zora's Domain throne room**, where lit torches ring a sunken area.

Use the **Gale Boomerang** to **blow out every torch**; the chest appears underwater. Equip **Iron Boots** to sink to it.

Requires: **Gale Boomerang**, **Iron Boots**.
