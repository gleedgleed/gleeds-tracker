# Ilia Charm

Same trigger as **Ilias Charm**: **defeat the Bulblins attacking the Hidden Village** and **Impaz** hands over Ilia's Charm (the Horse Call). This file exists because the apworld's world graph uses the name "Ilia Charm" while `locations.json` uses "Ilias Charm" -- both refer to the same item.

Requires: **Bow** (recommended), Hidden Village reached.
